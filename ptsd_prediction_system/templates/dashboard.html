Research Methodology

About the Prediction Model

Based on peer-reviewed clinical AI research. The ML model was trained on validated datasets and uses explainable AI for clinical transparency.

Model Architecture

A Random Forest classifier trained on multi-modal clinical data including biometric, trauma-exposure, psychiatric, and lifestyle factors. Cross-validated with 5-fold stratified splits.

Random Forest (500 estimators)
5-fold Stratified Cross-Validation
SMOTE oversampling for class balance
GridSearchCV hyperparameter tuning

Input Features

The model ingests 20+ clinical variables across four domains, selected using SHAP-based feature importance analysis.

Vital Parameters (Height, Weight, BMI, Age)
Trauma Exposure Events
Medical & Psychiatric History
Lifestyle & Socioeconomic Factors

SHAP Explainability

SHAP values are computed for every prediction, providing clinicians with interpretable feature attribution scores for full model transparency.

The model was ethically reviewed and validated against independent clinical datasets. Bias audits were performed across demographic subgroups.
